orbit-brief.md

The site is a constellation. Six project nodes orbit slowly around a centre point. Clicking a node pulls it to the centre, the rest park in a flat arc at the top, and speech bubbles appear underneath saying what that project is, followed by a strip of work thumbnails and link chips.

It is a conversation, not a grid. The bubbles are Madani speaking in first person. Hierarchy lives in the writing, not in type size. Every node is the same size deliberately.
